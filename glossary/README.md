# Glossary

The site's **Vocabulary** page is built from the files in this folder. Each
file is a topic, shown in the order of the file names.

```
title: Truth Tables
note: An optional sentence shown under the title.
Tautologous: Describes a statement that is true in every row of its truth table.
Contingent: Describes a statement that is true in some rows and false in others.
```

- **Add a term:** add a line `Term: definition` to a file. The term ends at the
  first colon followed by a space.
- **Add a topic:** create a new `.txt` file, such as `07-fallacies.txt`. Without
  a `title:` line, the file name is used ("07-fallacies" becomes "Fallacies").
- Terms appear in the order you write them. Lines starting with `//` are comments.

Commit, and the site updates within a minute or two.
